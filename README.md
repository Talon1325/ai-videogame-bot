# ai-videogame-bot
## Introduction
My first personal AI project making an AI video game bot. My goal in this project is to use python's autoGUI package to navagate and play minecraft! The next goal is to automate the bot to be able to learn from previous play throughs to be able to fight mobs and coordinate without manual modifications. I hope to learn more about to coding in python and minimizing the use of memory, so my computer can withstand the storage needed to use multiple play throughs to advance the capabilities of the bot.
